# 上岸罗盘 现状走查报告（R176 UI/UX 原型重设计 · 第一步）

走查时间：2026-08-04 · 实测环境：Chrome，视口 桌面 1440×900 / 平板 768×1024 / 移动 375×812
覆盖页面：体制内/校招/编制三板块列表（表格+卡片视图）、统一筛选面板+保存筛选、岗位详情抽屉、全局搜索（Ctrl K）与聚合搜索结果页、收藏面板（含推送订阅设置）、报考日历、今日更新、攻略页、数据看板侧栏、跨设备同步码。
截图目录：`assets/screenshots/current/`（文件名 = 视口-页面）。

## 总体评价

功能非常完整（三板块聚合、快捷预设、竞争参考、日历导出、推送订阅、同步码），信息密度也符合招聘工具类产品的预期。但整体呈现"功能堆叠"形态：首屏被 5 层控制区（横幅、搜索、四个下拉、一键匹配、热门搜索、保存筛选）占满，真正的岗位内容在桌面端要滚动约一屏半才能看到；三板块的筛选交互形态互不一致；视觉上以描边+浅灰为主，层级扁平、缺少品牌记忆点，暗色模式存在但令牌不成体系。移动端能用，但仍是"桌面缩窄"的布局思路，筛选/视图切换按钮一排四个占位大、点击目标层级不清。

### P3 — 打磨
| # | 页面/视口 | 问题 |
|---|---|---|
| P3-1 | 全站 | 圆角/间距不统一：pill 全圆角、卡片 12px、输入框 8px 混用；页面左右留白桌面 24px 偏小 |
| P3-2 | 顶栏 | 桌面顶栏 7 个入口全部同权重（今日更新/日历/求职攻略/最近浏览/我的收藏），缺主次 |
| P3-3 | 暗色模式 | 主题切换仅顶栏小图标（自动/亮/暗三态循环），暗色下部分标签（如"今日截止"红底）对比度不足 |
| P3-4 | 攻略页 | 以抽屉形式打开（#tips），长文无目录粘性导航；移动端 #tips 深链未能稳定打开抽屉 |
| P3-5 | 同步码 | 入口埋在收藏面板"更多"里，跨设备同步作为核心留存功能可见性低 |
| P3-6 | 文案 | "隐藏已截止/隐藏已看过"等否定式 pill 与"全部/公务员"等筛选 pill 混排，语义分组不清 |

## 结论 → 设计方向（第二步依据）

1. **首屏还内容**：压缩控制区为单行工具栏（搜索+筛选按钮+视图切换+排序），预设/速览/横幅合并为一条可横滑的"场景入口"，岗位列表桌面首屏可见。
2. **三板块一级化+筛选统一**：顶部/底部一级导航固定三板块+日历+更新；三板块共用同一套筛选面板骨架（关键词、地区级联多选、学历、类型、时间），差异项作为板块专属区。
3. **移动优先重排**：移动端用紧凑双行卡片列表（标题+单位 / 标签行+截止），筛选走底部抽屉，底部导航 5 项（体制内/校招/编制合并为"岗位"+ 日历 + 搜索 + 收藏 + 我的）。
4. **现代视觉体系**：建立 Tailwind 设计令牌（品牌色阶、语义色、字阶、间距、圆角、阴影、暗色映射），表面分层（page/card/raised），详情抽屉加锚点导航与带文字操作按钮。
5. **收藏=任务流**：收藏面板以"投递漏斗"列表为主体，提醒/推送/同步码收进"设置"二级页签。
